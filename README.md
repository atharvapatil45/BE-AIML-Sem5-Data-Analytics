# 📊 Data Analytics – BE AIML Semester 5

This repository contains my **Data Analytics practicals, experiments, and code implementations** performed as part of my **BE Computer Engineering – Artificial Intelligence & Machine Learning (AIML), Semester 5** coursework.

The repository focuses on understanding how data can be **collected, cleaned, analyzed, visualized, and interpreted** using Python and popular data analytics libraries.

## 📌 Topics Covered

* Data Loading and Exploration
* Data Cleaning and Preprocessing
* Handling Missing Values
* Handling Zero Values
* Statistical Analysis
* Mean, Median and Mode
* Data Visualization
* Histograms
* Correlation Analysis
* Correlation Matrix and Heatmap
* Sampling Techniques

  * Simple Random Sampling
  * Stratified Sampling
  * Systematic Sampling
* Central Limit Theorem
* Exploratory Data Analysis (EDA)
* Basic Machine Learning concepts

## 🛠️ Technologies & Libraries

* **Python**
* **Pandas** – Data manipulation and analysis
* **NumPy** – Numerical computations
* **Matplotlib** – Data visualization
* **Seaborn** – Statistical visualization
* **Scikit-learn** – Data preprocessing and machine learning
